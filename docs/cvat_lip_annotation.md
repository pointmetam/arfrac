# CVAT Lip Annotation

CVAT is the annotation workspace for cleaner lip masks. It does not replace the
ARKit UV pipeline; it only helps produce better 2D labels before projection.

## Start Local CVAT

```bash
colima start --cpu 4 --memory 8 --disk 80

cd /Users/lee/CodeBuddy/leyi/arface/third_party/cvat
docker compose up -d
```

Open:

```text
http://localhost:8080
```

Stop it when finished:

```bash
cd /Users/lee/CodeBuddy/leyi/arface/third_party/cvat
docker compose down
```

## Annotation Classes

Create three mask labels:

- `upper_lip`
- `lower_lip`
- `inner_mouth`

The final combined label format stays:

- `0`: background
- `1`: upper lip
- `2`: lower lip
- `3`: inner mouth

## Upload Images

Use the portrait frames generated by:

```bash
.venv-training/bin/python training/prepare_sam_lip_annotation.py \
  --session /private/tmp/arface-uv-recordings-new/20260528-180100 \
  --output-dir training/outputs/sam2_lip_annotation_20260528-180100 \
  --stride 4 \
  --max-frames 80 \
  --overwrite
```

Upload:

```text
training/outputs/sam2_lip_annotation_20260528-180100/images
```

For a quick smoke test, upload:

```text
training/outputs/sam2_lip_annotation_20260528-180100_sample/images
```

## Export Back To Training

Export masks from CVAT into:

```text
training/outputs/sam2_lip_annotation_20260528-180100/masks/upper_lip
training/outputs/sam2_lip_annotation_20260528-180100/masks/lower_lip
training/outputs/sam2_lip_annotation_20260528-180100/masks/inner_mouth
```

Then continue with:

```bash
.venv-training/bin/python training/combine_sam_lip_masks.py \
  --input-dir training/outputs/sam2_lip_annotation_20260528-180100/masks \
  --output-dir training/outputs/sam2_lip_annotation_20260528-180100/combined_masks \
  --image-dir training/outputs/sam2_lip_annotation_20260528-180100/images \
  --preview-dir training/outputs/sam2_lip_annotation_20260528-180100/combined_previews
```

After preview looks clean, project to ARKit UV using
`docs/sam2_lip_annotation_pipeline.md`.

## Important Limitation

CVAT Community is good for annotation and export. Built-in SAM2 video tracking is
not guaranteed in the community self-host setup, so the fallback is:

1. Annotate key frames in CVAT.
2. Use an external SAM2/SAMannot tool to propagate masks if needed.
3. Put the exported class masks back into the folder layout above.
4. Run combine, UV projection, and UV student training.

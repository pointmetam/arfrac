# 妆境 AR

妆境 AR 是一个面向全球用户的 AI 全妆试妆与美妆内容传播平台。

用户可以通过手机摄像头实时体验底妆、眉妆、眼影、腮红、修容、高光和口红，并进行拍照、录视频和分享。后续平台将支持美妆博主上传可试用的妆造模板、教程和产品信息。

## 当前状态

- iOS AR 人脸跟踪原型
- 唇部专项分割模型训练与 Core ML 导出
- 3D/UV 面部映射验证
- Metal/GPU 妆效渲染原型
- AR 全妆产品规划与介绍页

当前重点是提高不同肤色、光线、脸型和动态表情下的边缘贴合、覆盖完整度和实时稳定性。

## 技术路线

```text
人脸跟踪
  -> 全脸解析
  -> 局部精修模型
  -> 3D / UV 面部映射
  -> Metal / GPU 妆效渲染
```

## 运行环境

- iPhone 12 或更新设备
- iOS 18 或更新版本
- Xcode
- CocoaPods

安装依赖后打开 `arface.xcworkspace`。训练脚本和模型实验依赖请参考 `training/README.md`。

## 项目页面

介绍页位于 `docs/index.html`，可通过 GitHub Pages 发布。

## 目录说明

- `arface/AR/`：AR 与人脸跟踪相关代码
- `arface/Models/`：iOS 端 Core ML 模型
- `training/`：模型训练、评估和导出脚本
- `docs/`：项目介绍页和技术文档

## 免责声明

项目仍处于研发阶段，AR 妆效在不同设备、光线、脸型和表情下的表现可能存在差异。
